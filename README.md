# IT313 React Components and JSX

**Name:** Zild Jan F. Abuga-a
**Section:** IT2R3

## Description
A React Native student roster app that displays student cards with their name, course, units, and conditional Full Load labels.

## Components
- `StudentCard`: Displays one student's information using props.
- `StudentRoster`: Stores student data, displays the student count, maps students into cards, and reverses their order.

## Concepts Used
- Functional components and props
- Destructuring and JSX expressions
- Conditional rendering with `&&`
- `.map()` and unique keys
- `useState` and array reversal

## How to Run

```bash
npm install
npx expo start
```

Open the app using Expo Go or a compatible emulator.
